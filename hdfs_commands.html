HDFS Commands Reference Guide

Note on command prefixes: hadoop fs works with any Hadoop-compatible file system, while hdfs dfs is specific to HDFS. This guide uses hdfs dfs throughout.
hadoop fs generic

Interacts with ANY Hadoop-compatible file system (local, HDFS, S3, etc.).

hdfs dfs HDFS only

Interacts only with the Hadoop Distributed File System.

1 · Check Running Daemons & Local FS
1 jps
$ jps
Lists all running Java processes (Hadoop daemons) on the current machine.
2 ls
$ ls /home/cloudera/Desktop
Lists contents of a local file system directory.
3 hadoop fs
$ hadoop fs -<command>
Interacts with ANY Hadoop-compatible file system (distributed, local, cloud).
4 hdfs dfs
$ hdfs dfs -<command>
Interacts ONLY with HDFS. (Used in all commands below).
2 · Dealing with Directories
5 mkdir
$ hdfs dfs -mkdir <directory_name>
hdfs dfs -mkdir student_data
Creates a directory in HDFS.
5.1 mkdir -p
$ hdfs dfs -mkdir -p <parent>/<child>
hdfs dfs -mkdir -p /user/cloudera/student_data/ahmed
Creates nested directories (parents created if needed).
Use -p to create parent directories automatically.
5.2 subdirectory
$ hdfs dfs -mkdir <existing>/<new_sub>
hdfs dfs -mkdir student_data/mohamed
Creates a subdirectory inside an existing folder.
6 rmdir
$ hdfs dfs -rmdir <directory_name>
hdfs dfs -rmdir student_data
Removes an empty directory. For non‑empty directories, use hdfs dfs -rm -r.
3 · Dealing with Files
7 touchz
$ hdfs dfs -touchz <file_name.extension>
hdfs dfs -touchz report.txt
Creates an empty file in HDFS.
8 rm
$ hdfs dfs -rm <file_name.extension>
hdfs dfs -rm report.txt
Removes files only (use -r for recursive removal of folders).
4 · Copy / Move (Local ↔ HDFS)
9 copyFromLocal
$ hdfs dfs -copyFromLocal <local> <hdfs_dest>
hdfs dfs -copyFromLocal local_report.txt /user/data/
Copies a file from local file system to HDFS.
10 put
$ hdfs dfs -put <local> <hdfs_dest>
hdfs dfs -put local_report.txt student_data
Uploads a local file into HDFS (similar to copyFromLocal).
12 copyToLocal
$ hdfs dfs -copyToLocal <hdfs> <local_dest>
hdfs dfs -copyToLocal report.txt ~/Desktop/
Copies a file from HDFS back to the local file system.
13 cp
$ hdfs dfs -cp <source_hdfs> <dest_hdfs>
hdfs dfs -cp student_data/report.txt student_data/ahmed/
Copies a file within HDFS.
5 · View, Move & Advanced Operations
14 cat
$ hdfs dfs -cat <file_name.extension>
hdfs dfs -cat report.txt
Displays file content on terminal. Also verifies if a file exists in HDFS.
15 mv
$ hdfs dfs -mv <source> <dest>
hdfs dfs -mv student_data/report.txt student_data/ahmed/
Moves (cuts) a file within HDFS.
16 setrep -w
$ hdfs dfs -setrep -w <number> <file_path>
hdfs dfs -setrep -w 3 /user/data/report.txt
Changes replication factor. The -w flag waits for replication to complete.
17 appendToFile
$ hdfs dfs -appendToFile <local_src> <hdfs_dest>
hdfs dfs -appendToFile new_logs.txt /user/logs/master_log.txt
Appends contents of local file(s) to an existing HDFS file.
